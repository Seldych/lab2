## Архитектура

### `OptimizeResult`
Все методы возвращают единый dataclass:

```python
@dataclass
class OptimizeResult:
    x: np.ndarray           # найденная точка
    iters: int              # число итераций
    trajectory: List[float] # траектория значений f(x_k)
    converged: bool = True  # флаг сходимости
```

Добавление новых полей не ломает существующие вызовы.

### `EvalTracker`
Обёртка над функцией/градиентом/гессианом с подсчётом вызовов.

- `f(x)`, `g(x)`, `h(x)` — инкрементируют счётчики.
- `peek(x)` — возвращает значение $f(x)$ **без** инкремента счётчика. Используется для вывода и построения траекторий, чтобы не искажать статистику.

### `build_kwargs(name, tol)`
Формирует параметры вызова метода с учётом его сигнатуры:

- `line_search_tol` — для методов, использующих поразрядный поиск (наискорейший спуск, сопряжённые градиенты, покоординатный спуск).
- `use_analytical` — для градиентных методов первого и второго порядка.

### Единая точность одномерного поиска
Константа `LINE_SEARCH_TOL = 1e-6` в `main.py`, `task4.py`, `task6.py` обеспечивает согласованность сравнения методов между заданиями.

### `identify_minimum(x, known_minima, tol)`
Определяет, в какой из известных локальных минимумов попал алгоритм. Используется в задании 6 для функции Химмельблау.

## Критерии сравнения

- Число итераций.
- Число вызовов $f$, $\nabla f$, $H$ (через `EvalTracker`).
- Время CPU (через `time.perf_counter()`).
- Точность решения $\|x^* - x_{\text{exact}}\|$ (для заданий с известным минимумом).
- Флаги преждевременного окончания (задание 5).
- Индекс попавшего минимума (задание 6).

## Ключевые результаты

### Задание 2 (овражная функция)
- Метод Ньютона: минимальное число итераций на квадратичных функциях.
- Сопряжённые градиенты эффективнее наискорейшего спуска при больших $a$.
- Прямые методы требуют много вычислений функции.

### Задание 3 (тестовая функция №3)
- Метод Ньютона сходится за 1 итерацию (квадратичная функция).
- Градиентные методы дают ошибку $\sim 10^{-6}$ при $\varepsilon = 10^{-3}$.

### Задание 4 (сравнение)
- На овраге ($a=250$) метод Ньютона выигрывает по итерациям, но требует гессиан.
- Сопряжённые градиенты — лучший компромисс для плохо обусловленных задач.

### Задание 5 (Розенброк)
- Точность одномерного поиска критически влияет на итоговую точность.
- При грубом `line_search_tol` методы «застревают» вдали от минимума.
- Метод Ньютона нестабилен из-за плохой обусловленности гессиана.

### Задание 6 (Химмельблау)
- Все градиентные методы детерминированно сходятся к одному минимуму для фиксированной $x_0$.
- Смена $x_0$ приводит к попаданию в другой минимум.
- Локальные методы не гарантируют нахождение глобального минимума на многомодальных функциях.

## Ограничения

- Поразрядный поиск использует фиксированный начальный шаг $h = 1.0$ — настраивается в `utils.py`.
- Для прямых методов (симплекс, Хук-Дживс) аналитические производные не используются.
- Случайный поиск использует фиксированный `seed=42` — результат детерминирован, но не репрезентативен для стохастического метода.
- Траектории по $x$ (координатам) не визуализируются — только значения $f(x_k)$ и точки сходимости.
