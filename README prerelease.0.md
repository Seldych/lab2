# Лабораторная работа №2: Методы минимизации функций многих переменных

Реализация численных методов безусловной минимизации на Python (NumPy) по методичке 2019 года.

## Требования

- Python 3.8+
- NumPy

```bash
pip install numpy
```

## Структура проекта

```
lab2/
├── utils.py      # Утилиты: трекер вычислений, конечно-разностные аппроксимации, поразрядный поиск
├── methods.py    # Реализация 7 методов минимизации
├── main.py       # Выполнение заданий 1-3 и сравнение эффективности
└── README.md
```

## Запуск

```bash
python main.py
```

## Выполненные задания

1. **Задание 1** — реализация всех методов с аналитическими и конечно-разностными производными
2. **Задание 2** — тестирование на овражной функции $f(x) = x_1^2 + a \cdot x_2^2$ при $a \in \{1, 250, 1000\}$ и $\varepsilon \in \{10^{-3}, 10^{-5}\}$
3. **Задание 3** — минимизация тестовой функции №3: $f(x) = 254x_1^2 + 506x_1x_2 + 254x_2^2 + 50x_1 - 130x_2 + 111$

## Критерии сравнения

- Число итераций
- Число вызовов функции $f$, градиента $\nabla f$ и гессиана $H$
- Точность решения $\|x^* - x_{\text{exact}}\|$

## Ограничения

- Задания 4-6 из методички не реализованы (по условию задачи)
- Поразрядный поиск использует фиксированный начальный шаг $h=1.0$ — при необходимости настраивается в `utils.py`
- Для прямого поиска (симплекс, Хук-Дживс) аналитические производные не используются
